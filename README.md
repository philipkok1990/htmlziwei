# ☯️ 紫微斗数排盘系统 (Ziwei Dou Shu System)

基于 100% 原生 HTML5 + CSS3 + Vanilla JavaScript 的紧凑型紫微斗数排盘与多维运程断语系统。

---

## 📱 1. 响应式布局规范 (Responsive Layout Rules)

为了提升在电脑与手机端的阅读体验，系统采用灵活动态的 CSS 布局：

* **电脑端 (Desktop Mode ≥ 850px)**：
  - **左侧**：480px 宽度的紧凑型 4×4 紫微命盘。
  - **右侧**：Main Tab (命盘/运程 TAB)、运程三级选择框、四化/化忌/自化/飞星备注卡片、以及 13 个子 TAB 解盘。
* **手机端 (Mobile Mode < 850px)**：
  - **上方**：4×4 命盘。
  - **下方**：Main Tab、三级下拉菜单、四化备注卡片与 13 个子 TAB 解盘。

---

## 👁️ 2. 字体与四化视觉强化

1. **字体强化**：星曜名称采用 `font-weight: 800` 加粗加大显示，确保在所有屏幕上清晰易读。
2. **四化与自化颜色**（参照“文墨天机”）：
   - 🟢 **化禄 (Lu)**: `#2baf4a` (绿色白字)
   - 🟣 **化权 (Quan)**: `#9c27b0` (紫色白字)
   - 🔵 **化科 (Ke)**: `#03a9f4` (蓝色白字)
   - 🔴 **化忌 (Ji)**: `#f44336` (红色白字)
   - 🟠 **自化 (Zi)**: `#ff9800` (橙色白字)
3. **化象与飞星备注卡片**：
   - 命盘隔壁实时列出当前选中宫位的生年四化、自化忌、双化（2化/3化）及飞星提醒。

---

## 🔀 3. TAB 联动架构
- **Main Tab**：命盘 TAB vs 运程 TAB。
- **运程控制器**：十年大限 -> 流年 -> 流月 三级联动。
- **13 个子 TAB**：总结解盘 + 12 宫位解盘。
