# 紫微斗数系统开发文档 (规则与约定)

## 1. 默认测试数据
- **性别**: 男 (阳男)
- **公历生日**: 1990年04月24日 12:15 PM (午时)
- **农历生日**: 庚午年三月三十日 午时

## 2. 核心计算规则
1. **干支纪年**: 1990年 -> 庚午年 (庚干：阳金，午支：阳火)。
2. **命宫与身宫起法**: 
   - 顺数生月，逆数生时起**命宫**。
   - 顺数生月，顺数生时起**身宫**。
3. **局数推算**: 根据命宫天干（五虎遁）与命宫地支，依据纳音五行定局（水二局、木三局、金四局、土五局、火六局）。
4. **紫微星定位**: 根据农历生日日数与局数求商与余数定紫微星位置。
5. **四化天干（庚干）**: 
   - 太阳化禄、武曲化权、太阴化科、天同化忌。

## 3. 前端交互约定
- `dict.js`: 仅存储静态映射关系（星曜五行、四化规则、解盘文案）。
- `ziwei.js`: 负责所有的干支历法转换、安星算法，并渲染到网页。
