# 紫微斗数排盘系统开发指南 (AI Collaboration & System Rules)

## 1. 项目设计原则
* **纯前端实现**：100% HTML5 + CSS3 + Vanilla JavaScript (ES6+)，不依赖后端。
* **第三方库依赖**：仅允许使用 `lunar-javascript` 进行公历、农历及基础干支换算。
* **分工设计**：
  * `index.html`：页面结构与表单。
  * `style.css`：布局与视觉设计（Grid 12 宫格 + 中宫）。
  * `dict.js`：仅存储静态数据（天干地支、五行局、十四主星、吉凶星等）。
  * `ziwei.js`：纯逻辑处理（排五行局、安紫微系星、安天府系星、四化等）。

## 2. 后续计算逻辑迭代路线图
1. **安命宫与身宫**（已在 ziwei.js 完成基础框架）。
2. **定五行局**（根据命宫天干地支，结合纳音六十甲子定水二局、木三局、金四局、土五局、火六局）。
3. **起紫微星**（根据农历生日数与五行局数计算紫微星落入的地支宫位）。
4. **安十四主星**：
   * 紫微系星：紫微、天机、太阳、武曲、天同、廉贞。
   * 天府系星：天府、太阴、贪狼、巨门、天相、天梁、七杀、破军。
5. **起生年四化**（化禄、化权、化科、化忌）。
6. **安六吉六凶星与大限/小限**。

## 3. AI 协作注意事项
* **规则修改规范**：向 `dict.js` 添加数据结构时，必须确保名称与标准传统术语一致。
* **计算逻辑函数化**：所有的星曜定位计算逻辑必须在 `ziwei.js` 中写成独立的纯函数（Pure Function），便于单独测试。
